# حسابات ماضي (MADI Accounts)

تطبيق محاسبة لماضي لتجهيز المطابخ: فواتير بيع وشراء، عروض أسعار، مخزون مع مقاسات وأسعار، زباين وموردين مع كشف حساب، صندوق ومصاريف، وتقارير أرباح. بالدولار والليرة.

- بيتنزّل كتطبيق (PWA) على الكمبيوتر والتلفون وبيشتغل بلا إنترنت.
- البيانات محفوظة على Supabase ومشتركة بين كل المستخدمين، مع نسخة على كل جهاز.

## الملفات
- `index.html` التطبيق كامل.
- `config.js` رابط Supabase والمفتاح العام (publishable).
- `sw.js` بيخلّي التطبيق يشتغل بلا إنترنت.
- `supabase-setup.sql` بيجهّز قاعدة البيانات (مرة وحدة).
- `seed/catalog.json` و `img/` كتالوج العبدالله (221 منتج).

بلا build: ملفات جاهزة بتنرفع على Vercel أو أي استضافة static.
